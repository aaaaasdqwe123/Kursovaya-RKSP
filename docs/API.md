# REST API

Базовый путь: `/api`. JSON UTF-8. Все суммы — целые копейки; валюта RUB. Для защищённых маршрутов нужен `Authorization: Bearer <token>`. Даты операций — ISO-8601 UTC, `expiresAt` — epoch milliseconds.

| Метод и путь | Тело / параметры | Ответ |
|---|---|---|
| GET /health | Без авторизации; вне /api | 200 `{ "status":"ok" }`, проверяет БД |
| POST /auth/register | `email,password,name,phone` | 201 `token,expiresAt` |
| POST /auth/login | `email,password` | 200 `token,expiresAt` |
| POST /auth/logout | Без тела | 204, отзыв текущей сессии |
| GET /profile | — | `id,email,name,phone` |
| GET /wallet | — | `id,balance,currency` |
| GET /cards | — | Массив `id,alias,last4` |
| POST /cards | `{ "alias":"Основная" }` | 201 виртуальная карта, максимум 5 |
| DELETE /cards/{id} | UUID | 204 либо 404 |
| GET /settings | — | `{ "darkTheme":false }` |
| PUT /settings | `{ "darkTheme":true }` | Сохранённые настройки |
| POST /transfers | См. ниже; заголовок Idempotency-Key | 200 операция, включая повтор |
| GET /transactions | `q`, `direction=ALL/IN/OUT`, `offset=0` | `{ "items":[], "nextOffset":null }`, 30 на страницу |
| GET /search | `q` (1–100 символов) | Массив SearchItem |
| GET /search/history | — | Массив SearchItem, новые первыми |
| POST /search/history | `{ "id":"service:mobile" }` | Обновлённая история, максимум 10 |
| DELETE /search/history | — | 204 |

## Регистрация

```json
{"email":"new@example.test","password":"LongPassword123!","name":"Новый пользователь","phone":"+79990000009"}
```

Email нормализуется `trim().lowercase()`. Телефон обязателен в международном формате с `+`, уникален. Пароль 12–128 символов, имя 2–80. Email/телефон уже занят: 409. Неправильный логин/пароль: 401 с общим сообщением. Регистрация создаёт пустой кошелёк, средства не выдаются через API.

## Перевод

```http
POST /api/transfers
Authorization: Bearer <token>
Idempotency-Key: 3a2c6931-0dab-4eeb-a275-f1b7ecf2321c
Content-Type: application/json
```

```json
{"recipient":"+79990000002","amount":12550,"note":"За обед","kind":"PHONE"}
```

`PHONE`: recipient — полный телефон. `CARD`: UUID существующей виртуальной карты. `SERVICE`: код услуги, например `mobile`. Отправитель определяется из токена. Допустимая сумма: 1–100000000 копеек. Перевод себе запрещён, комментарий не более 200 символов. Комиссия отсутствует.

```json
{"id":"...","fromAccount":"...","toAccount":"...","amount":12550,"note":"За обед","createdAt":"2026-10-06T10:00:00Z","kind":"PHONE","counterparty":"Борис","incoming":false}
```

Повторный запрос с тем же ключом и тем же телом возвращает исходную операцию. Поля тела должны совпадать, включая комментарий. При timeout результат неизвестен; повторите исходный запрос с прежним ключом. Не генерируйте новый ключ для сетевой повторной попытки. На стороне сервера ключи хранятся вместе с операциями без срока удаления.

## Поиск

```json
[{"id":"service:mobile","title":"Мобильная связь","subtitle":"Оплата услуги","kind":"SERVICE","recipient":"mobile"}]
```

Получатели доступны по точному телефону/email, услуги по подстроке без учёта регистра. История хранит идентификаторы выбранных результатов. Имена разрешаются при чтении, поэтому обновление имени отражается в истории. Нажатие результата вызывает POST /search/history, затем заполняет экран перевода. Пустой q возвращает 400; поиск `%` не означает SQL wildcard.

## Ошибки

Формат прикладных ошибок: `{ "code":"insufficient_funds", "message":"Недостаточно средств" }`.

| HTTP | Значение |
|---|---|
| 400 | Некорректный JSON, поля, сумма, UUID, отсутствует ключ перевода |
| 401 | Неверные учётные данные, отсутствующий/истёкший/отозванный JWT |
| 404 | Получатель/карта/выбранный результат отсутствует либо не принадлежит пользователю |
| 409 | Дубликат регистрации, недостаток средств, лимит карт/баланса, конфликт ключа |
| 429 | Лимит запросов; клиент показывает сообщение, повторить позже |
| 500 | Внутренняя ошибка без раскрытия SQL/stacktrace клиенту |

Ошибки Ktor rate limiter (429) могут иметь стандартное тело; клиент поддерживает fallback по HTTP status. Лимиты: 10 auth-запросов в минуту на IP, 120 API-запросов в минуту на пользователя. TLS завершается на reverse proxy. CORS не нужен нативному Android-клиенту.
