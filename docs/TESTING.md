# Проверки

Автоматические тесты проверяют результат и инварианты, а не только наличие файлов. Фактический результат последнего запуска записан отдельно в VERIFICATION.md.

|---|---|
| RulesTest — 15 | Запятая, одна копейка, ноль, отрицательная сумма, лишние знаки, экспонента, лимит, переполнение, нормализация email, пробелы email, короткий пароль, формат телефона, лимит 10, повторный выбор, точный вывод суммы |

| PaymentViewModelTest — 6 | Восстановление запроса; очистка результата; повтор запроса; loading; отбрасывание старого результата; сохранение выбранного объекта и переход к переводу |
| RemoteRepositoryTest — 5 | Ключ сохранён до отправки; timeout и новый repository; запрет другого платежа; очистка после отказа; сохранение при истечении сессии |

Интеграционные тесты используют настоящий PostgreSQL, не H2 и не in-memory имитацию. Изоляция выполняется TRUNCATE в отдельной базе. CI запускает Testcontainers в Linux с Docker.

## Ручная приёмка Android

1. Зарегистрировать пользователя; закрыть приложение, открыть снова — сессия восстановлена, баланс нулевой.
2. Неправильный пароль — русское сообщение без открытия главного экрана.
3. Войти Алисой, отправить 125,50 ₽ Борису; проверить остатки 874,50 / 1125,50 ₽ и две стороны истории.
4. Попытаться отправить больше остатка — баланс не меняется, операции нет.
5. После отправки оборвать сеть до ответа; восстановить сеть и нажать «Проверить / повторить» — один перевод. Повторить после остановки процесса приложения.
6. Найти «Мобильная» — progress, результат. Выбрать его — заполненный перевод и запись в истории.
7. Ввести неизвестную услугу — «Ничего не найдено».
8. Выключить сервер, выполнить поиск — ошибка и «Обновить»; включить сервер и повторить — тот же запрос.
9. Ввести запрос, повернуть экран portrait → landscape → portrait — текст сохранён.
10. Пустое поле — placeholder и нет кнопки «Очистить». Набрать текст — кнопка появилась. Нажать — текст/результаты очищены, клавиатура закрыта.
11. Нажать пустое поле — история; выбрать уже имеющийся элемент — он один и сверху; очистить историю — список пуст после нового входа.
12. Сохранить более 10 разных результатов через тестовые услуги — видны последние 10.
13. Включить тёмную тему, перезапустить приложение и войти снова — настройка сохранена.
14. Создать карту Бориса, скопировать UUID, перевести Алисой на UUID; удалить карту — остаток не изменился, новый перевод на удалённый UUID возвращает 404.
15. Фильтры входящие/исходящие и поиск по имени/сообщению возвращают только собственные операции. Проверить страницу более 30 операций.
16. Logout — старый JWT больше не разрешает /wallet; следующая сессия другого пользователя не показывает чужие данные.
17. На маленьком экране и в landscape формы прокручиваются, клавиатура не закрывает кнопки; проверить TalkBack и увеличенный шрифт.

## Соответствие методическим указаниям

| Требование | Реализация |
|---|---|
| Kotlin, собственный Ktor сервер, без Firebase | Все *.kt, server/Main.kt, Gradle modules |
| PostgreSQL / схема | V1__initial.sql, Database.kt, Flyway |
| Clean + MVVM + Hilt | domain/, data/, presentation/, di/ |
| Регистрация и авторизация | AuthScreen, /auth/register, /auth/login |
| Placeholder / условная очистка / клавиатура | SearchScreen + onFocusChanged + KeyboardActions |
| Поворот и восстановление текста | SavedStateHandle/query |
| Пустой результат / ошибка / повтор | SearchState, submitSearch(retry=true) |
| История выбранных результатов ≤ 10 | /search/history + SQL UPSERT/prune |
| ProgressBar | LinearProgressIndicator для поиска и общих действий |
| Тёмная тема | MaterialTheme + /settings |
| Профиль, баланс, карты, операции, переводы | Compose screens + защищённые API routes |
| Не менее 10 сценариев | 48 автоматических сценариев и 17 ручных |
